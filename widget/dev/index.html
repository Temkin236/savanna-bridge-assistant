Try asking the assistant:

Features to Verify

  • Keyboard & Focus: Press Tab to the bottom-right launcher button, press Enter/Space to open. Focus moves inside. Press Escape to close, focus restores to launcher.
  • Bilingual Toggle: Toggle between English and Amharic (አማርኛ) using the header button.
  • Voice Input: Click the microphone button to test recording and review editable transcript before sending.
  • Read-Aloud Playback: Click "Read Aloud" on any assistant response to test audio playback, speed control (0.75x - 1.5x), and sound-off text equivalence.
  • Support Needs Panel: Check preferences with zero proof or documentation requested.
  • Barrier-free Account Linking: Generate a one-time 6-digit code or confirm a code from Telegram without phone or national ID.
  • Live Help Handoff: Request mentor assistance with explicit consent and learner-controlled screen sharing.
